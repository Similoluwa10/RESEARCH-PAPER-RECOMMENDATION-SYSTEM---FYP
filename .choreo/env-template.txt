## ============================================================================
## HOW TO DEPLOY
## ============================================================================

# 1. Database Setup
#    - Create PostgreSQL service in Choreo
#    - Replace DB_HOST, DB_PASSWORD with actual values
#    - Note the connection string

# 2. API Service Setup
#    - Create API service in Choreo (apps/api)
#    - Set these secrets in Choreo Console:
#      DATABASE_URL, JWT_SECRET_KEY, APP_ENV, DEBUG, GROQ_API_KEY
#    - Copy the provided API service URL

# 3. Web Service Setup
#    - Create Web service in Choreo (apps/web)
#    - Set NEXT_PUBLIC_API_URL to the API service URL from step 2
#    - Deploy

# 4. Post-Deployment
#    - Run database migrations
#    - Update CORS origins with web service URL
#    - Test integration

## ============================================================================
## SECURITY BEST PRACTICES
## ============================================================================

# ✅ DO:
# - Store all secrets in Choreo Console (not in version control)
# - Use strong, randomly generated passwords
# - Rotate secrets regularly (quarterly recommended)
# - Use separate credentials for development/staging/production
# - Enable HTTPS/TLS for all services
# - Restrict database access to Choreo services only

# ❌ DON'T:
# - Commit this file with real values to GitHub
# - Use simple/predictable passwords
# - Share credentials in messages or tickets
# - Use same credentials across environments
# - Expose API keys in browser console
# - Store credentials in .env files in repo
